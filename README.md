# JavaScript Practice

A collection of small JavaScript projects I built while learning the language. 

Built using HTML, CSS and JavaScript :)


## Projects

### 🎮 Number Guessing Game
- Custom minimum and maximum bounds
- Tracks attempts and remaining guesses
- Practices DOM manipulation, events and random number generation (the basic stuff) :)

## 🌡️ Temperature Converter

- Converts between Celsius and Fahrenheit
- Practices functions, DOM manipulation and conditional logic
- Uses Flexbox for layout and custom component styling, Flexbox was fun ngl :)

# 🎲 Dice Roller

- Generates a user-specified number of dice rolls
- Displays random values between 1 and 6
- Uses JavaScript arrays to store generated values
- Practices loops, functions, arrays and random number generation
